# v0.3 PR 描述建议

## PR 标题

升级至 v0.3：新增 YAML 编辑、修改历史、章节化输出、台词索引和快速启动体验

## 功能描述

本 PR 在 v0.2 基础上继续增强用户体验和剧本编辑能力。新增零安装快速启动服务，降低评委和用户的本地运行门槛；新增 YAML 在线编辑器，用户可以直接修改生成结果，并复制或下载编辑后的版本；新增修改历史记录，帮助用户了解本次编辑过程；升级 YAML Schema，按章节组织剧本，并将台词单独拉出为 dialogue_index；新增改编风格选项，支持忠于原文、增强戏剧冲突化和口语化三种生成方式。

## 实现思路

- 使用 `backend.dev_server` 提供仅依赖 Python 标准库的本地演示服务，`start.bat` 和 `start.sh` 调用该服务；
- 将 YAML 结果展示区由只读展示升级为可编辑 textarea；
- 前端监听 YAML 编辑器输入事件，记录生成、编辑、复制、下载、恢复等历史；
- 后端生成逻辑新增 `adaptation_style` 参数，根据用户选择调整 Prompt 和本地演示生成策略；
- YAML 结构新增 `chapter_scripts` 和 `dialogue_index` 字段；
- 校验器兼容 v0.2 旧格式，同时对 v0.3 推荐字段给出提示；
- 前端新增章节剧本预览和台词索引预览。

## 测试方式

1. 双击 `start.bat` 或执行 `python -m backend.dev_server`，确认无需执行 pip install 即可启动；
2. 访问 `http://127.0.0.1:8000`；
3. 点击“填入示例”，选择本地演示模型和任一改编风格；
4. 点击“生成剧本”，确认 YAML 中包含 `chapter_scripts` 和 `dialogue_index`；
5. 编辑 YAML 内容，确认修改历史出现记录；
6. 点击“校验编辑版”，确认编辑后的 YAML 可校验；
7. 点击“复制 YAML”和“下载 YAML”，确认使用的是编辑后的内容；
8. 分别选择“忠于原文”“增强戏剧冲突化”“口语化”，确认生成结果中的 `adaptation_style` 和台词/动作表达有所变化；
9. 执行 `pytest`，确认测试通过。
