# 开发计划与 PR 记录说明

## MVP 开发顺序

1. 初始化项目仓库与目录结构；
2. 新增 YAML Schema 设计文档；
3. 新增示例小说文本；
4. 搭建 FastAPI 后端接口；
5. 实现章节解析；
6. 实现剧本生成逻辑；
7. 实现 YAML 校验；
8. 实现前端输入、预览和下载；
9. 完善 README；
10. 录制 Demo 视频并补充链接。

## PR 拆分建议

每个 PR 只做一件事，便于体现持续交付：

- PR1：初始化项目仓库与基础目录结构
- PR2：新增剧本 YAML Schema 定义文档
- PR3：添加三章节小说测试样本
- PR4：新增章节解析模块
- PR5：新增剧本生成接口
- PR6：接入大模型生成 YAML 剧本
- PR7：新增 YAML 校验模块
- PR8：新增前端页面
- PR9：增加 YAML 下载和示例填充
- PR10：完善 README 和 Demo 链接

## 增强版升级记录建议

本版本在第一版 MVP 基础上新增以下能力，建议拆分为独立 PR 提交：

1. 增加复制和下载成功提示；
2. 增加 txt、md、docx、图片上传解析接口；
3. 增加七牛云 API 与本地演示模型切换；
4. 增加人物关系图谱生成接口与前端 SVG 可视化；
5. 优化页面视觉风格、按钮状态和错误提示。

每个 PR 仍需包含：

- 功能描述；
- 实现思路；
- 测试方式；
- 是否新增第三方依赖说明。
