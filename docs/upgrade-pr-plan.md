# 增强版 PR 拆分建议

为了符合比赛“持续提交、每个 PR 只做一件事”的要求，建议你不要一次性提交全部升级代码，而是按下面顺序拆分提交：

## PR1：增加复制和下载成功提示

功能描述：
为复制 YAML、下载 YAML 增加 Toast 提示，解决用户点击后不知道是否成功的问题。

实现思路：
在前端新增 showToast 方法，复制和下载成功/失败时展示右上角提示。

测试方式：
生成 YAML 后点击“复制 YAML”和“下载 YAML”，确认页面右上角出现成功提示。

## PR2：增加文件上传解析能力

功能描述：
新增文件上传入口，支持 txt、md、docx 和图片文件解析。

实现思路：
后端新增 `/api/extract-text` 接口，txt/md 直接解码，docx 使用 python-docx，图片使用 Pillow + pytesseract OCR。

测试方式：
上传 examples/novel_sample.txt，确认文本自动填入输入框；上传 docx 文件，确认段落能被提取。

## PR3：增加七牛云和本地模型切换

功能描述：
页面新增模型方案选择，支持“本地演示模型”和“七牛云 API”。

实现思路：
GenerateScriptRequest 增加 provider 和 model 字段；provider=local 使用规则生成，provider=qiniu 调用七牛云 OpenAI 兼容接口。

测试方式：
选择本地演示模型，无需 API Key 可以生成；配置 `.env` 后选择七牛云 API 可以调用真实模型。

## PR4：增加人物关系图谱可视化

功能描述：
根据生成的 YAML 剧本自动生成人物关系图谱。

实现思路：
后端解析 characters 和 scenes，同一场景出现的角色建立边；前端使用原生 SVG 渲染节点和连线。

测试方式：
生成示例剧本后检查页面下方是否出现人物节点和连线。

## PR5：优化页面美观度和体验

功能描述：
优化页面头图、卡片、按钮、输入区、结果区、图谱区样式，提升 Demo 观感。

实现思路：
重写 CSS 布局，使用渐变头图、卡片阴影、响应式布局、状态提示。

测试方式：
访问首页，检查页面是否正常展示；缩小窗口，确认布局可用。
